# Transformer与“未来”？ <span class="animated-dot"></span>

从一块为了让《雷神之锤》画面更流畅的显卡，到如今给无数学生和打工人续命的 AI，像是一场由电子游戏、脑洞大开的程序员以及神秘皮衣男共同编织的一个美丽意外。


---

## 见证诞生：英伟达与GPU

上世纪 90 年代，3D 游戏开始风靡。但是像《毁灭战士》（Doom）或《毁灭公爵 3D》这样的游戏，本质上是“伪 3D”（2.5D）。虽然墙壁是 3D 的，但怪物和道具其实是一张张平面的贴图纸片（Sprite）。

后来，[《雷神之锤》](https://store.steampowered.com/app/2310/Quake/)（Quake，1996年发布）彻底抛弃了纸片，游戏里的所有怪物、武器、房间架构全部由真实的 3D 多边形（Polygons）构成。

那么代价是什么呢？计算量呈指数级暴涨，当时的 CPU 不出意外地遇到了计算瓶颈。为了处理 3D 游戏中的多边形的位置和光影，需要同时计算成千上万个位置的顶点和像素。虽然 CPU 精通微积分和各种复杂的逻辑控制，但是因为他只有几个核心，只能排队一个一个算。

有人看准了机会。1999 年，[英伟达（NVIDIA）](https://www.nvidia.com/)发布了 **GeForce 256**。

> 英伟达在这款产品上[首次提出](https://blogs.nvidia.com/blog/first-gpu-gaming-ai/)了 **GPU（Graphics Processing Unit，图形处理器）** 的概念。

与侧重低延迟复杂逻辑控制的 CPU 不同，GPU 采用的是高吞吐量的架构设计。它精简了控制单元与缓存，转而集成了数以千计的算术逻辑单元（ALU）。虽然单个核心的独立控制能力有限，但极其擅长执行数据并行（Data Parallelism）计算。这种天生的**大规模并行计算**架构，专为图形渲染和大规模矩阵运算而生。

---

## 现实需求：数据的伪装

随着 GPU 的并行计算性能与带宽逐渐超越同时期的 CPU，高性能计算（HPC）领域的学者与研究人员开始尝试将这股算力引入非图形领域，用于物理模拟、气象预报及金融建模。

然而，当时的 GPU 缺乏通用的计算编程接口，仅支持 OpenGL 和 DirectX 等标准图形 API。为了突破这一限制，研究人员建立了一套精妙的映射（Mapping）机制，将通用计算任务强行嵌入图形管线（Graphics Pipeline）中：

- 将待处理的科学数据映射为 **纹理贴图（Texture Maps）** 中的像素颜色值
- 将多维数学矩阵映射为 3D 几何体的 **顶点网格（Vertex Meshes）**
- 将具体的计算算法与数学公式改写为 **像素着色器（Pixel Shader）** 代码

在这种机制下，可怜的 GPU 表面上以为自己还在执行标准的图形渲染流程，而其底层的算术逻辑单元（ALU）实际上已被转化为流处理器，用于求解流体力学等数值计算。这种通过图形 API 驱动通用计算的尝试，正是早期 GPGPU（通用图形处理器） 的技术前身。

## 嗅探新机：一无所有还是赢者通吃？

英伟达 CEO 黄仁勋敏锐地发现了这个趋势。他决定不再让科学家们偷偷摸摸地骗显卡。

2006 年，英伟达推出了 **CUDA（Compute Unified Device Architecture，统一计算设备架构）**。

[CUDA](https://developer.nvidia.com/cuda/toolkit) 的出现是颠覆性的。它提供了一种通用的编程接口，让程序员可以正大光明地直接用 C/C++ 语言来编写在 GPU 上运行 reduction、矩阵乘法等算法，再也不用费劲地把数据伪装成像素来骗 GPU 了。

然而，这一举动在当时被华尔街视为疯狂的败家行为。为了让所有显卡都支持 CUDA，英伟达的芯片成本飙升，利润大跌，股价一度跌掉 80%。但老黄顶住了压力，这一布线就是六年，直到那个改变命运的夏天。

## 初现端倪：AlexNet 点燃深度学习

2012 年，ImageNet [计算机视觉大赛](https://image-net.org/challenges/LSVRC/2012/)。

多伦多大学的 Alex Krizhevsky 和他的导师 Geoffrey Hinton 带着一个名为 **AlexNet** 的深度卷积神经网络（CNN）参赛，以碾压第二名的绝对优势夺冠。

此前，深度神经网络因为计算量太大，一直被学术界冷落。而 Alex 另辟蹊径，他用了 **两块英伟达的 GTX 580 显卡** 来训练这个模型。

> **AlexNet 的成功向全世界证明了一件事：**
> 神经网络（算法）+ 大数据（数据）+ GPU（算力）= 真正的智能化。

这一刻，沉寂多年的深度学习彻底被 GPU 唤醒，英伟达也从一家“臭打游戏的显卡公司”正式踏上了“AI 算力巨头”的转型之路。

---

## 黄金时代：从 AlexNet 到 RNN

在 AlexNet 之后的五年里，深度学习迎来了全面大爆发：

* **计算机视觉（CV）领域**：VGG、ResNet 等更深的模型不断刷新人类的视觉极限。
* **生成模型**：GAN（生成对抗网络）横空出世，AI 开始学会“画画”。
* **自然语言处理（NLP）领域**：RNN（循环神经网络）和 LSTM（长短期记忆网络）成为了处理文本和语音的主力军。

然而，此时的 NLP 遇到了一个致命的瓶颈：**RNN 家族是串行结构**。它们必须读完第一个词，才能读第二个词。这种“字字句句按顺序来”的特性，导致它**无法完美享受 GPU 的大规模并行算力**。

---

## 改写规则：Transformer 出世

为了打破 RNN 的串行枷锁，2017 年，谷歌团队发表了一篇名震天下的论文：**《Attention Is All You Need》**，正式提出了 **Transformer** 架构。

Transformer 的核心在于**自注意力机制（Self-Attention）**。它彻底抛弃了循环结构，允许模型**并行处理**整篇文本中的所有单词。


# Transformer结构  
### 整体结构
Transformer由输入部分，编码器组，解码器组，输出部分构成，每个编解码器组又由多个相同的编解码器堆叠组成。
编码器大致由多头自注意力层和位置前馈网络层组成，解码器大致由掩码多头自注意力层，交叉注意力层和位置前馈网络层组成。不同层之间传输数据前还要进行 Dropout 和 Add&Norm(残差连接和层归一化)来规范化运算。

### 输入部分  
需要进行词嵌入，把词语转换成向量，随后进行位置编码。位置编码有助于使机器获取词语在句子中的具体位置，结合语境来提高预测准确率。

### 编码器组  
编码器首先接收词嵌入与位置编码后的向量列表输入(列表大小基本上是训练数据集中最长句子的长度)。然后需要经过多头自注意力层，进行Add&Norm，随后进入位置前馈网络。位置前馈网络是一个全连接前馈网络，每个位置的词都单独经过这个完全相同的位置前馈网络，其由两个线性变换，即两个全连接层组成。第一个全连接层先通过线性变换拓展向量的维度，然后经过非线性的 ReLU 激活函数，获得更好的处理复杂数据的能力。第二个全连接层是一个无激活函数的纯线性变换层，作用是将向量的维度压缩还原为原始维度。经过位置前馈网络后，最后一个编码器最终输出上下文向量矩阵（Hidden States），它将被送入每个解码器的交叉注意力层，用来生成交叉注意力机制中的 $K$ 和 $V$
### 解码器组  
解码器的掩码多头自注意力层内有两种掩码，填充掩码(Padding Mask)和序列掩码(Sequence Mask)。最底层解码器掩码多头自注意力层的输入是词嵌入与位置编码后的输入，其他层解码器自注意力层的输入则来自于上一个解码器的输出。交叉自注意力层接受编码器产生的K和V矩阵，也接受来自掩码多头自注意力层输出的Q矩阵。交叉自注意力层的输出经过Add&Norm后便进入位置前馈网络。解码器的位置前馈网络和编码器中的结构功能基本相同。

### 输出部分
解码器组的最终输出是一个向量，要把这个向量转换为一个词，
就要通过一个线性层(是一个简单的全连接神经网络，其将解码器栈的输出向量映射到一个更长的 logits 向量)，随后进入Softmax层，进行label smoothing，最后得到一个输出矩阵，这个矩阵的每一行是输入的每个词的预测，结果矩阵每个分量的大小代表输出词表中对应单词的概率。


### 细节理解补充
- 最底层编解码器的输入是词嵌入，其他编解码器的输入则是上一个编解码器的输出
- 解码器为自回归的预测，第一层输入为[sos]符号(start of sequence)，标志预测任务的开始，[eos]符号(end  of sequence)则标志结束，[sos]符号也有与其相关的预测概率值
- 不同层编解码器的自注意力层和位置前馈网络层不共享权重
- 残差连接只在单个编码器层内部(如多头自注意力和前馈神经网络之间)使用，不在不同的编码器层之间的数据传递时使用，其思想为将输入直接加到输出上，进行一个跳跃连接
- Dropout机制通过随机屏蔽神经元来防止发生过拟合，label 
smoothing通过调整真实标签的分布防止过拟合
- Padding Mask(填充掩码)    
因为每个批次输入序列的长度是不一样的，所以要对输入序列长度进行修正，在较短的输入序列后面补0，截断太长的输入序列。
而填充的0无意义，所以要通过Padding Mask在这些位置的值加上一个非常大的负数，从而经过 Softmax 后，这些位置的概率就会接近 0，减小对结果的影响。Padding Mask在编码器的多头自注意力层，解码器的掩码多头自注意力层以及交叉注意力层使用。
- Sequence Mask(序列掩码)        
只在解码器的掩码多头自注意力层使用，防止解码器看到当前预测词后的词而影响预测结果。产生一个下三角部分值全为0，上三角部分为很大的负数(负无穷)的矩阵，进行矩阵加法后只保留句子预测词及之前的词。
- 自注意力机制     
有时一个词语有多个意思，在句子中的具体意思就需要结合语境来确定，这就是自注意力机制要完成的事情。  
计算两词语的相似性就是两个词语向量的点积，自注意力机制的核心是Scaled Dot-Product Attention(缩放点积注意力)，大致步骤如下：
1. 将词嵌入向量合在一起得到一个输入矩阵，将这个矩阵乘以经过训练得到的三个权重矩阵而得到三个新矩阵:查询矩阵Q、关键字矩阵K和值矩阵V，这三个新矩阵的维数小于嵌入矩阵的维数。K是被查询词自身，Q表示另一个词语，V是移动原向量使其向语义偏移的向量      
2. 计算分数，将查询向量Q与正在评分的相应单词的关键向量K点积，计算后应用Padding Mask   
3. 将分数除以关键矩阵K维度的平方根         
4. 将分数通过softmax归一化，归一化函数为e的当前值次方除以e的所有值的和     
5. 将值矩阵V乘以softmax分数，为求和做准备   
6. 权值矩阵求和，产生自注意力层的输出  

- 多头自注意力机制   
在注意力机制获取QKV矩阵之后，再乘一个矩阵可以得到多个QKV。多头自注意力意味着有多个不同的头共同处理输入矩阵，但是每个头在得到QKV矩阵时所使用的系数矩阵不同。通过多个头，模型能够以不同的角度理解输入序列的上下文，从而捕捉到更丰富的信息，在处理复杂的输入时表现更好，避免单一头造成过拟合。最后把多个头输出的矩阵再乘以一个系数矩阵，就得到了最终的输出。
   
- 残差连接和层归一化(Add&Norm)     
公式为LayerNorm(x+sublayer(x))，其中[x+sublayer(x)]是残差连接得到的的值，残差连接可以保留原始的输入值，相当于在原始输入值的基础上做出了修改，
进行层归一化可以使数据标准化分布，使训练更加稳定。


### Decoder-only（GPT-2/3）
#### 输入   
每一个token会有词嵌入和位置嵌入，词嵌入对应每一个token在词表中的编号，而位置嵌入对应在输入序列中的位置，将这两个向量相加，就得到了输入的嵌入。以上嵌入就作为transformer块的输入。

#### 多头自注意力机制  
前面提到的输入首先会经过层归一化，然后便进入自注意力运算。第一步是给上面的归一化后的列生成查询向量Q、键向量K，值向量V。这三个向量是由输入中的每一列与QKV三个权重矩阵相乘并加上偏置（kx+b）得到的列向量。
- 一个Q向量和所有K向量相乘，QK点积是衡量两个向量之间相似程度的方法。如果两者相似，点积会很大，如果不同，就会很小或为负。这些点积的结果形保存为注意力矩阵，之后会除以 根号下(|Q/K/V 向量的长度|)来防止Softmax梯度消失。以上的运算结果随后经过Softmax归一化，再之后每个结果与对应的一个V向量相乘，再然后对这些乘积求和，就是每个注意力头最后的输出
- 不同注意力头的输出之后会直接堆叠在一起。在 GPT 中，每个注意力头内部的向量长度等于 C / num_heads。这确保了当我们把它们重新堆叠在一起时，我们能够重新得到原始输入特征维度 C
- 现在得到了自注意力层的输出。这个输出不是直接传递到下一阶段，对于输入的首层是逐元素地加到输入嵌入上，对于非首层，相加的对象是上一层 Transformer 块的输出，即是一种残差连接。

#### 前馈神经网络
自注意力的输出会再次经过层归一化，然后经过一组全连接的前馈神经网络，MLP的结果会再次以残差连接的形式与输入进行相加

#### 前面这两个多头自注意力和FFN及归一化、残差连接就组成了一个完整的transformer块

#### 输出
多层堆叠transformer块的输出会经过层归一化，然后通过一个无偏置的简单线性层，即进行矩阵乘法。该变换实际上是为词汇表中的每个词为每个列生成一个分数logits，这里logits随后会经过softmax来转换成输出的概率。可以通过设置温度参数来改变不同概率值占的相对大小，使得较大值和其他值的差别减小，但是大小相对排序是不会变的


这种架构简直就是为 GPU 量身定制的。GPU 那些数以万计的核心终于可以火力全开，不再需要等待上一个词的计算结果。

## 智能爆发：从 LLM 到 Agent

有了 Transformer 和 GPU 的完美结合，AI 进化开启了加速模式。

### LLM 的大炼丹时代

既然并行度拉满了，科学家们便开始奉行“大力出奇迹”的 Scaling Law（规模法则）。从 GPT-3 到如今统治战局的各种万亿参数多模态大模型，参数量呈指数级暴涨。GPU 从单卡演变成了成千上万块 H100、B200 组成的算力集群。

### 从指点江山到御驾亲征

如果说大模型（LLM）是 AI 的大脑，那么 **Agent（智能体）工具** 就是给大脑装上了手和脚。

现在的 AI 不再只是陪你聊天的打字机，而是能够自主思考、调用工具、拆解任务并执行复杂工作流的数字化员工：

* 它们可以自主浏览网页、调用 API 查数据。
* 能够自动编写、运行并调试代码（如各类 AI 编程助手）。
* 甚至能像人类一样直接操控电脑屏幕（Computer Use）完成复杂的办公流程。

## 无用的思考
在本人看来，对于目前基于Transformer的LLM，本质是做预测，是在已有人类经验的分布上做插值，也许没有办法真正跳出已有范围之外。它能做的事需要有人做过，且留下了足够的文本痕迹。一旦需要真正的推理或者任务要靠经验直觉，它就开始产生"幻觉"。    

甚至对目前的整个计算机领域来说，图灵、冯诺依曼架构本质上是确定性状态机。即使加入随机数，也只是伪随机，种子确定，输出就确定。     

我们真正缺的是开放性——系统能提出训练分布之外的问题，能对从未见过的情境形成有效模型。不同于强化学习的为了达成某个具体目的，是否能让AI像生物一样，单纯是为了“好奇心”去探索?不过是LLM还是具身智能，都任重道远。
